# JavaScript-harjoitukset

## JavaScript – Moduuli 1

Olen tehnyt seuraavat harjoitustehtävät:

1. Tulostaminen konsoliin
2. Käyttäjän tervehtiminen
3. Kolmen luvun summa, tulo ja keskiarvo
4. Tylypahkan tupien arvonta
5. Karkausvuoden tarkistaminen
6. Neliöjuuren laskeminen
7. Noppien silmälukujen summa
8. Karkausvuosien tulostaminen
9. Alkuluvun tarkistaminen
10. Noppien todennäköisyyden laskeminen

## Tehtävien suorittaminen

Jokaisella tehtävällä on oma HTML- ja
JavaScript-tiedosto.

Tehtävät voi suorittaa avaamalla
HTML-tiedoston selaimessa.
